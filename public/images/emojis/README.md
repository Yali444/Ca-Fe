# Emoji Images

התיקייה הזו מכילה קבצי PNG של אימוג'ים שמחליפים את האימוג'ים הטקסטואליים ברקע של האתר.

## קבצים קיימים

- `1zpresso.png` - ☕ קפה (מחליף גם 🍪 ו-💫)
- `Carafe.png` - 🥐 קרפה קפה (מחליף גם 🧁 ו-🌟)
- `EKG.png` - 🍰 עוגה (מחליף גם 🍩)
- `v60.png` - 🥖 לחם (מחליף גם ✨)

## מיפוי אימוג'ים

המערכת ממפה את האימוג'ים הטקסטואליים לקבצי PNG כדי ליצור חווייה ויזואלית ייחודית עם ציוד קפה אמיתי.

## גדלים ומאפיינים

- גודל מקורי: משתנה (כל קובץ בגודל שונה)
- פורמט: PNG עם רקע שקוף
- איכות: גבוהה להצגה מיטבית

## איך להשתמש

הקוד ב-`EmojiImage.tsx` מזהה אוטומטית את קבצי ה-PNG ומשתמש בהם במקום אימוג'ים טקסטואליים ברקע המונפש.
